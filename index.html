WallForge

Your Wallpaper Engine library on Wayland, played by one small Rust renderer. This page serves the pacman repository.

Install on Arch or CachyOS

Add the repository once:

sudo tee /etc/pacman.d/wallforge.conf <<'EOF'
[wallforge]
SigLevel = Optional
Server = https://pgm1207.github.io/WallForge/arch/x86_64
EOF
grep -q wallforge.conf /etc/pacman.conf || echo 'Include = /etc/pacman.d/wallforge.conf' | sudo tee -a /etc/pacman.conf

Then install and keep it updated like any other package:

sudo pacman -Sy wallforge

Packages are unsigned; SigLevel = Optional accepts them without a key. If you prefer, build from source with the install script instead.

What is in here

arch/x86_64/ holds the package archive and the pacman database, rebuilt on every release. The newest three versions are kept.
