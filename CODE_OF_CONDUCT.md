# Code of conduct

Be decent. This project is one person plus contributors, and the issue tracker is not a place to win arguments.

Concretely:

- **Criticism is welcome, contempt is not.** "This renders the shadows wrong, here is a screenshot and the wallpaper
  link" is useful. "This is garbage" is not.
- **No harassment** based on who someone is, what they use, or how they write English.
- **Stay on topic.** Bug reports are about WallForge; unrelated politics, piracy and personal feuds belong elsewhere.
- **Do not post Wallpaper Engine files, paid content or other people's work** in issues or pull requests. That is a
  licensing problem, not just a rule.

If someone's behaviour makes the project worse for others, the maintainer can edit or remove comments and, for
repeated or serious cases, block the account. If it is about you, report it privately via
[SECURITY.md](SECURITY.md#reporting-a-vulnerability) or the repository's moderation tools.

Credit where it is due: fixes are credited in the release notes.
